# Godot Multiplayer Tutorial

This tutorial was created by Firebelley and can be accessed at Udemy from this link: [Click Me](https://www.udemy.com/course/create-a-complete-online-cooperative-multiplayer-game-in-godot-4/). I highly recommend it to learn about Godot's high level multiplayer solution.

In addition to this being the completed base tutorial with some small semantic changes and the such, I also integrated (albeit buggy) GodotSteam so that you can play this game via the Steam network.

As of writing this 10/14/2026, I have no plans to work upon this any further, but below will be a list of possible features that may be integrated if I have nothing better to do.
